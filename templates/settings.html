Phone still can't connect?
  • "Connection refused": check the number after the : matches the address above. It can change, for example if another copy of {{ APP_NAME }} was already open. Close all other {{ APP_NAME }} windows and reopen it.
  • The page keeps loading, then times out: the computer's firewall is probably blocking it. Windows: when Windows asks whether to allow ScienceInventory (or Python) on networks, tick Private networks and click Allow. If you missed that, search the Start menu for "Allow an app through Windows Firewall". Mac: System Settings → Network → Firewall → Options, and allow ScienceInventory (or Python).
  • The phone must be on the same Wi-Fi as this computer, not on mobile data. Some school and guest Wi-Fi networks don't let devices reach each other at all; if so, ask IT, or use a network where that's allowed.
  • Chromebook: apps in the Linux terminal aren't reachable from other devices until you add port forwarding: Settings → Advanced → Developers → Linux → Port forwarding → add port {{ phone.urls[0].split(':')[2].rstrip('/') }} (TCP) and turn it on. Then use the Chromebook's own Wi-Fi address (Settings → Network → your Wi-Fi) with that port.
